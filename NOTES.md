1. Getting Started
Ініціалізація проекту за допомогою create-next-app, знайомство зі структурою папок (app/, public/) та запуск сервера розробки.


2. CSS Styling
Робота з глобальними стилями, CSS-модулями та інтеграція Tailwind CSS для стилізації компонентів.


3. Optimizing Fonts and Images
Використання компонентів next/font для автоматичного завантаження шрифтів Google та next/image для оптимізації розміру та пріоритетності зображень.


4. Creating Layouts and Pages
Створення файлової системи маршрутизації: page.tsx для контенту сторінок та layout.tsx для спільних UI-елементів (наприклад, Sidebar), які не перерендерюються.


5. Navigating Between Pages
Використання компонента <Link /> для швидкої клієнтської навігації та хука usePathname для визначення активного стану посилань.


6. Setting Up Your Database
Створення бази даних PostgreSQL на Vercel, налаштування змінних оточення в .env та запуск скрипта для "посіву" (seeding) початкових даних.


7. Fetching Data
Використання Server Components для прямого отримання даних через SQL-запити та знайомство з механізмом Waterfall.


8. Static and Dynamic Rendering
Різниця між статичною генерацією (під час збірки) та динамічним рендерингом (під час запиту) за допомогою unstable_noStore.


9. Streaming
Покращення UX за допомогою loading.tsx (скелетони) та Streaming with Suspense для завантаження частин сторінки окремо.


10. Adding Search and Pagination
Реалізація пошуку та пагінації за допомогою URL-параметрів (URLSearchParams), що дозволяє ділитися станом сторінки через посилання.


11. Mutating Data
Використання Server Actions для створення, оновлення та видалення запитів без створення окремих API-ендпоінтів.


12. Handling Errors
Обробка помилок за допомогою error.tsx для вилову непередбачуваних багів та функція notFound() для обробки відсутніх ресурсів (404).


13. Improving Accessibility
Покращення доступності форм за допомогою eslint-plugin-jsx-a11y, серверна валідація даних та виведення помилок через useFormState.


14. Adding Authentication
Налаштування безпеки за допомогою NextAuth.js (Auth.js), захист маршрутів через Middleware та логіка авторизації користувачів.


15. Adding Metadata
Додавання метаданих (заголовки, описи, Open Graph зображення) для покращення SEO та відображення сторінок у соцмережах.
